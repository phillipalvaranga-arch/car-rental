# Car Rental Finder

Installable web app for finding the best and cheapest rental car (home base Frisco, TX 75034; DFW and Love Field; Montego Bay and Kingston, Jamaica).

- **Search**: one tap opens price searches on Kayak, Expedia, Priceline, Hotwire, Rentalcars.com, Turo, Costco Travel, AutoSlash and 13 rental companies. Trip details are filled in where the site supports links.
- **Compare**: J.D. Power 2026 North America Rental Car Satisfaction scores, loyalty programs, member discounts, DFW/DAL fee guide, website status.
- **My quotes**: private quote tracker (saved on the device only) with export/import.
- **Calculator** and **Save money** tips (including Jamaica).

Live: https://phillipalvaranga-arch.github.io/car-rental/

`data/companies.json` holds curated, sourced facts. `data/status.json` is written daily by `.github/workflows/status.yml`.

Information only. The app never books, never takes payment, and never asks for a driver's license number, card number, SSN or password.
